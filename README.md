# Real Estate Property Management System

## Overview
Built on Salesforce using LWC and Apex.

## Features
- Property Management with image upload
- Server-side pagination (25 records/page) with filters
- Tenant Management
- Lease Agreement with automated email reminders
- Maintenance Request auto-assignment
- Vendor Management
- Dashboard with occupancy rate, expiring leases, maintenance stats

## Test Coverage
91% code coverage

## Tech Stack
- Salesforce LWC
- Apex Controllers
- SOQL with dynamic queries
- ContentVersion for file storage
